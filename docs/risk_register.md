# リスク登録簿

デモおよび PoC で想定される代表的リスクを一覧化する。発生確率と影響度は当該 PoC で再評価する。

| ID | リスク | 影響 | 緩和策 | 残余対応 |
|---|---|---|---|---|

## リスクトリアージ手順

1. PR またはデモ当日に新規リスクを検知したら、本ファイルに ID を採番して追記する（命名規則: `R-NN`）。
2. 緩和策が決まらないリスクは、`status: open` とし、PoC マネジメント会議で月次レビューする。
3. 緩和策が運用に乗ったリスクは `status: mitigated` とし、`docs/runbook.md` または該当 instruction へ反映する。
