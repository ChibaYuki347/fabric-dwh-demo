# 合成サンプルデータについて

本ディレクトリの CSV は、本デモで使う**完全合成**データである。実顧客・実取引・実支店との関連は一切なく、個人情報（氏名・住所・電話番号・口座番号体系）は含まない。

| ファイル | 行数（目安） | 用途 |
|---|---:|---|
| `branch.csv` | 8 | 支店マスタ。地域コードと開設日のみ |
| `customer.csv` | 25 | 顧客マスタ。氏名なし。セグメント・リスクスコア・開設日のみ |
| `account.csv` | 40 | 口座マスタ。顧客・支店・口座種別・状態 |
| `transaction.csv` | 80 | 取引明細。1週間分のサンプル |

## 使い方

- CSV → Fabric Lakehouse `bronze/` に投入し、`fabric/lakehouse/bronze_to_silver_mapping.md` のマッピングで Silver へ変換する想定。
- 件数照合や集計照合のデモを行うときに、CSV を「ソース真値」、Fabric Warehouse を「ターゲット」と見なして `tests/*.sql` を実行する。

## 規約

- ID は安定した昇順整数。`CustomerId 1-25`、`AccountId 1001-1040`、`BranchId 101-108`。
- 金額は架空の値で `DECIMAL(18,2)` の範囲内。
- 日付は 2026 年 4 月後半〜5 月上旬を基準にする。営業日と非営業日の混在を意図して残している。
- 列順序は対応する Bronze テーブル DDL に合わせる。

## 含まれないもの

- 実在の個人・法人を想起させる名称
- 暗証番号、認証情報、本物の金融機関識別子
- 個人情報保護法上の要配慮個人情報
